PMN-003 MONTAZH v0.3.8
======================
半自動映像構成装置 / Promnica

公開版の説明は README.md を参照してください。
「保存」は .montazh 1ファイルに台本・時間配置・音声キャッシュをまとめます。
VOICEVOX / VOICEVOX Nemo を自動起動したい場合は、詳細設定でインストール先フォルダを指定してください。
フォルダ未設定時は自動検索・自動起動を行いません。既に起動中ならそのまま接続します。

- 完成MP4と同じフォルダにSRTを置くと再生ソフトが自動読込して字幕が二重表示される場合があるため、SRTは `metadata/subtitles.srt` に出力します。
