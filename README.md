# PMN-003 MONTAZH

**半自動映像構成装置 / Promnica**

画面録画と台本から、VOICEVOXナレーション・字幕・元動画音声を合成し、ショート動画向けMP4を組み立てるWindows用デスクトップツールです。

MONTAZHはフル機能の動画編集ソフトではなく、**録画と台本を投入し、配置案を人間が必要な箇所だけ直して完成動画を出す**ことを目的にしています。

## 主な機能

- 1行＝1セリフの台本入力
- VOICEVOX / VOICEVOX Nemoによる読み上げ（詳細設定でフォルダを指定した場合のみ未起動時に自動起動）
- ナレーションと字幕の自動配置
- `.montazh` 1ファイルで台本・時間配置・音声キャッシュをまとめて保存/復元
- 生成済みVOICEVOX音声をキャッシュし、配置確認・再レンダリングを高速化
- 動画全体への均等配置を初期案として生成
- タイムライン上で開始位置をドラッグ調整
- Deleteキーで不要なセリフを削除
- 元動画音声のON/OFFと音量調整
- 縦1080×1920 / 縦720×1280 / 横1920×1080出力
- 任意アイコン画像の動画内表示
- 台本、字幕、設定、処理ログを出力フォルダへ保存
- `output/logs/app.log` にアプリ側の例外ログを保存

## Windows版を使う

GitHub Releasesから `PMN-003_MONTAZH_vX.X.X_Windows_x64.zip` を取得し、任意のフォルダへ展開してください。

1. `PMN-003_MONTAZH.exe` を起動（自動起動したい場合は詳細設定でVOICEVOX/Nemoフォルダを一度指定）
2. 元動画を選択
3. 台本を入力
4. 「配置を確認・修正」でタイミングを調整
5. 必要なら「保存」で `.montazh` プロジェクトを1ファイル保存
6. 「MP4を製造する」

完成物は既定では実行ファイルと同じ場所の `output` 以下へ保存されます。画面から別の保存先にも変更できます。

> VOICEVOX / VOICEVOX Nemo本体はMONTAZHに同梱していません。利用する音声ライブラリ側の規約・クレジット条件も確認してください。

## 台本

通常は1行に1セリフを書きます。

```text
人類は、動画編集に時間を使いすぎる。
そこで私は、動画自動製造機を製造した。
```

読み上げだけ変える場合:

```text
PMN-003を起動。 || ピーエムエヌ、ゼロゼロさんを起動。
```

時間を手動指定する場合:

```text
[00:08-00:14]
この場面で読むセリフ。
```

## ソースから起動

Python 3.12を推奨します。

```text
START.cmd
```

初回にプロジェクト専用の仮想環境を作成し、必要なPythonパッケージを導入します。

## Windows EXEをローカルビルド

Python 3.12をインストールしたWindowsで `BUILD_EXE.cmd` を実行してください。

生成先:

```text
dist/PMN-003_MONTAZH/PMN-003_MONTAZH.exe
```

公開版はPyInstallerの **onedir** 形式です。`PMN-003_MONTAZH.exe` だけを取り出さず、生成されたフォルダ一式で使用してください。

## v0.3.5 最終安定化

- `.montazh` に `schema_version` を追加し、未知schemaは明示的に拒否
- `.montazh` をAtomic Save化し、保存失敗時に最後の正常ファイルを維持
- Project A → B → Aで台本・手動配置・出力設定が混入しない復元を確認
- セリフ対応は `script_index` だけを信用せず、字幕＋読み上げ内容も照合
- 共通設定をアプリ本体外のローカル設定領域へ移動し `schema_version` を付与
- VOICEVOXの接続timeout / 読込timeout / HTTPエラーを明示的に処理
- 元動画をプロジェクト読込時と書出し前に検査
- 同一パスは同一の論理素材として扱い、ハッシュ・更新日時比較は行わない
- MP4は `video.mp4.part` へ生成し、検査成功後のみ最終名へ置換
- FFmpeg長時間処理は総時間ではなく進捗停止を検知して terminate → kill
- 「配置を確認」の処理段階ログを追加し、重い処理はWorker側のまま維持
- busy状態を IDLE / SAVING / LOADING / GENERATING / EXPORTING として最小管理
- 処理中の終了要求は安全停止後に終了

## Windows配布版の作成

`BUILD_EXE.cmd` を実行すると、PyInstallerの `--windowed --onedir` 形式でWindows版を作成します。

ビルド成功後は次の2つが生成されます。

- `dist/PMN-003_MONTAZH/PMN-003_MONTAZH.exe` — 動作確認用
- `release/PMN-003_MONTAZH_v0.3.8_Windows_x64.zip` — 配布用

配布時は **EXE単体ではなく release フォルダのZIPを配布**してください。`_internal` がPythonランタイム等を含むため、EXEだけでは起動できません。

公開前に配布ZIPを別フォルダへ展開し、EXE起動・プロジェクト保存/読込・VOICEVOX接続・MP4書出しを1回通すことを推奨します。


## Windows配布版のFFmpeg方針

正式配布ZIPにはFFmpegバイナリを同梱しません。MONTAZHは外部FFmpegを利用します。
利用者はFFmpegをPATHに配置するか、詳細設定で `ffmpeg.exe` を指定してください。
これにより、MONTAZHの配布物とFFmpegの再配布ライセンスを分離します。

新規ユーザー向けの初期表示は汎用化しています。ヘッダーは `VIDEO / REPORT`、タイトルは `サンプル動画`、台本は一般的な操作例です。既存 `.montazh` プロジェクトや旧schemaから読み込んだPromnica設定は変更しません。
